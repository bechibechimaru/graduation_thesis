# 質問表設計資料

## ディレクトリ構成

- `questionnaire.md`: 実験調査用の質問表（統制群と4つの実験条件を含む）
- `documentation.md`: 質問表の詳細ドキュメント（先行研究との比較、改善点、意図）

## 概要

本ディレクトリには、オンライン投票に関する実験調査の質問表とその詳細ドキュメントが含まれています。

### 主な改善点

1. **2×2要因計画の厳密な実施**
   - 政府信頼（高/低）× 技術信頼（高/低）の4条件を明確に定義

2. **概念の明確な分離**
   - 政府への信頼：選挙運営の公正性、透明性、選管の独立性
   - 技術への信頼：システムのセキュリティ、技術的堅牢性、監査可能性

3. **より現実的な表現**
   - 極端な対比を避け、実際の政策議論に近い状況を再現

4. **独立した操作チェック**
   - 政府への信頼と技術への信頼を独立して測定

## 使用方法

1. `questionnaire.md`を参照して、実際の調査で使用する質問表を作成
2. `documentation.md`を参照して、質問表の設計意図と改善点を理解

## 発表時の注意点

- 先行研究の3つの主要な問題点を明確に説明
- 改善点とその意図を具体的に説明
