# 分析

本章では、セクション3で提示した各仮説を、セクション4で測定した指標と重回帰分析を用いて検証する。各仮説群について、回帰分析の結果を表と図で示し、得られた結果の傾向を詳細に記述する。

## 1. H1：オンライン投票導入と投票参加意向（利便性向上仮説）

### 1.1 分析モデル

H1「オンライン投票が導入されている場合、導入されていない場合と比較して、投票参加意向が高まる」を検証するため、以下の重回帰分析モデルを推定した。

**モデル1（H1の検証）：**

Y1（投票参加意向）= β0 + β1×X1（オンライン投票導入）+ β2×Z1（政府信頼高）+ β3×Z2（技術信頼高）+ ε

ここで、Y1は投票参加意向（1-10の11段階スケール）、X1はオンライン投票導入ダミー（1=導入、0=非導入）、Z1は政府信頼高ダミー（1=高、0=低）、Z2は技術信頼高ダミー（1=高、0=低）である。

分析には、ロバスト標準誤差を用いた重回帰分析（`lm_robust`）を使用した。これにより、不均一分散の可能性に対処し、より信頼性の高い推定結果を得ることができる。

### 1.2 分析結果

表1に、H1の検証結果を示す。

**表1：オンライン投票導入が投票参加意向に与える影響（H1の検証）**

| 変数 | 係数 | 標準誤差 | p値 |
|------|------|----------|-----|
| （定数） | 7.425 | 0.130 | p < 0.001 |
| オンライン投票導入 | 0.573 | 0.150 | p < 0.001 |
| 政府信頼高 | 0.389 | 0.125 | p < 0.01 |
| 技術信頼高 | -0.077 | 0.151 | n.s. |
| R² | 0.022 | | |
| 調整済みR² | 0.019 | | |
| サンプルサイズ | 1,186 | | |
| RMSE | 2.143 | | |

注：n.s.は統計的に有意でないことを示す（p > 0.10）。

### 1.3 結果の解釈

表1の結果から、以下の点が明らかになった。

第一に、オンライン投票導入の係数は0.573であり、統計的に高度に有意である（p < 0.001）。この結果は、オンライン投票が導入されている場合、導入されていない場合と比較して、投票参加意向が平均で約0.57ポイント高くなることを示している。投票参加意向は1から10の11段階スケールで測定されているため、この効果量は実質的にも意味のある大きさであると言える。

第二に、統制変数である政府信頼高の係数は0.389であり、統計的に有意である（p < 0.01）。これは、政府への信頼が高い場合、投票参加意向が平均で約0.39ポイント高くなることを示している。一方、技術信頼高の係数は-0.077であり、統計的に有意ではない（p > 0.10）。これは、技術への信頼だけでは投票参加意向を説明できないことを示唆している。

第三に、モデルの決定係数（R²）は0.022であり、このモデルは投票参加意向の分散の約2.2%を説明している。この値は比較的小さいが、実験的な刺激のみを用いた分析としては妥当な水準であると考えられる。

図1は、オンライン投票導入の有無による投票参加意向の予測値平均を示したものである。図から明らかなように、オンライン投票が導入されている場合（導入あり=1）の投票参加意向は、導入されていない場合（導入なし=0）と比較して明確に高い。また、両群の95%信頼区間が重なっていないことから、この差は統計的に有意であることが視覚的にも確認できる。

![図1：オンライン投票導入が投票参加意向に与える影響（予測値平均）](../Statics/gra_thesis/h1_yosokuchi_plot.png)

注：エラーバーは、90％および95％信頼区間を示している。

### 1.4 仮説の判定

以上の分析結果から、H1「オンライン投票が導入されている場合、導入されていない場合と比較して、投票参加意向が高まる」は支持された。この結果は、オンライン投票の導入が投票コストを削減し、利便性を向上させることで、投票参加意向を高めるという理論的予測と整合的である。

## 2. H2：政府への信頼と投票参加意向・オンライン投票利用意向（政府信頼度仮説）

### 2.1 分析モデル

H2A「政府への信頼が高い場合、低い場合と比較して、投票参加意向が高まる」およびH2B「政府への信頼が高い場合、低い場合と比較して、オンライン投票の利用意向が高まる」を検証するため、以下の2つの重回帰分析モデルを推定した。

**モデル2A（H2Aの検証）：**

Y1（投票参加意向）= β0 + β1×X2（政府信頼高）+ β2×Z3（オンライン投票導入）+ β3×Z2（技術信頼高）+ ε

Y2（オンライン投票利用意向）= β0 + β1×X2（政府信頼高）+ β2×Z2（技術信頼高）+ ε

なお、モデル2Bの分析においては、オンライン投票導入群（`exp2_onlinevote = 1`）にサンプルを限定している。これは、オンライン投票が導入されていない群では、オンライン投票利用意向を測定していないためである。

第一に、モデル2A（投票参加意向を従属変数とする分析）において、政府信頼高の係数は0.389であり、統計的に有意である（p < 0.01）。この結果は、政府への信頼が高い場合、低い場合と比較して、投票参加意向が平均で約0.39ポイント高くなることを示している。

第三に、両モデルにおいて、技術信頼高の係数は統計的に有意ではない（モデル2A: -0.077, p > 0.10; モデル2B: -0.056, p > 0.10）。これは、政府への信頼を統制した場合、技術への信頼だけでは投票行動を十分に説明できないことを示唆している。

図2Aおよび図2Bは、政府への信頼の有無による投票参加意向およびオンライン投票利用意向の予測値平均を示したものである。

両図から明らかなように、政府への信頼が高い場合（高信頼=1）は、低い場合（低信頼=0）と比較して、投票参加意向およびオンライン投票利用意向の両方が高い。また、両群の95%信頼区間が重なっていないことから、この差は統計的に有意であることが視覚的にも確認できる。

### 2.4 仮説の判定

以上の分析結果から、H2A「政府への信頼が高い場合、低い場合と比較して、投票参加意向が高まる」およびH2B「政府への信頼が高い場合、低い場合と比較して、オンライン投票の利用意向が高まる」は支持された。

この結果は、政府への信頼が選挙制度全体への信頼を高め、投票の重要性を認識させることで、投票参加意向を向上させるという理論的予測と整合的である。特に、オンライン投票が政府によって運営される場合、政府への信頼が高い有権者は、オンライン投票システムも公正に運営されると信頼し、利用意向が高まることが示された。

Y2（オンライン投票利用意向）= β0 + β1×X3（技術信頼高）+ β2×M3（政府信頼高）+ β3×X3×M3（交互作用項）+ ε

以上の分析結果から、H4「技術への信頼が投票参加意向およびオンライン投票利用意向を高める効果は、政府への信頼が低い場合より、高い場合に強くなる」は支持されなかった。

この結果は、政府への信頼が技術への信頼の効果を調整するのではなく、むしろ政府への信頼自体が投票行動に直接的な影響を与えることを示唆している。すなわち、オンライン投票の受容においては、技術的な信頼性と制度的な信頼性が相互作用するのではなく、制度的な信頼性（政府への信頼）が独立して重要な役割を果たしていると考えられる。

## 5. H5A：政治関心によるオンライン投票導入の効果の調整

### 5.1 分析モデル

第二に、政府への信頼は、投票参加意向とオンライン投票利用意向の両方を有意に高める効果がある（H2A, H2B支持）。一方、技術への信頼は、いずれの従属変数に対しても有意な効果を持たない（H3A, H3B棄却）。この結果は、オンライン投票の受容において、技術的な信頼性よりも制度的な信頼性（政府への信頼）の方が重要であることを示している。

第三に、政府への信頼と技術への信頼の交互作用は統計的に有意ではなく（H4棄却）、政府への信頼が技術への信頼の効果を調整するという仮説は支持されなかった。むしろ、政府への信頼自体が独立して重要な役割を果たしていることが示唆される。

第四に、政治関心は投票参加意向に非常に強い影響を与える（係数2.077, p < 0.001）が、オンライン投票導入の効果を調整する作用は確認されなかった（H5A棄却）。これは、政治関心が投票行動の基本的な要因である一方、オンライン投票導入の効果は政治関心の水準に関わらず一定であることを示している。

第五に、インターネット使用頻度は、オンライン投票導入の効果を調整しない（H5B棄却）。この結果は、デジタル技術への親和性が、オンライン投票導入の効果に影響を与えないことを示唆している。

第六に、政府の責任認識は投票参加意向に一定の影響を与えるが、政府への信頼の効果を調整する作用は確認されなかった（H5C棄却）。

### 8.2 理論的含意

これらの発見は、オンライン投票の受容に関する理論的理解に重要な含意を持つ。

第一に、オンライン投票の導入効果は確認されたものの、その効果は個人の特性（政治関心、インターネット使用頻度）によって調整されるわけではない。これは、オンライン投票の利便性向上効果が、特定の層に限定されず、幅広い有権者に共通して作用する可能性を示唆している。

第二に、政府への信頼が技術への信頼よりも重要であるという発見は、オンライン投票が単なる技術的なシステムではなく、政府が運営する制度の一部として認識されていることを示している。すなわち、有権者はオンライン投票システムの技術的な安全性だけでなく、そのシステムを運営する政府の信頼性を重視していると考えられる。

第三に、政治関心の非常に強い主効果は、投票行動において基本的な政治的態度が重要であることを再確認させる。しかし、オンライン投票導入の効果が政治関心によって調整されないという発見は、オンライン投票が政治関心の低い層に特に有効であるという仮説を支持しない。

これらの理論的含意については、次章の考察においてさらに詳しく議論する。
