# データセットの概要と変数の測定方法

## 1. データセットの概要

本論文で使用するデータは、オンライン投票に関する実験調査によって収集されたものである。調査は、2026年1月3日から1月5日にかけて、オンライン調査として実施された。調査プラットフォームにはQualtricsを使用し、調査対象者はランサーズを通じて選定された。調査は明治大学によって実施され、明治大学倫理審査委員会による承認を予定している（承認番号は未定）。

調査では、18歳以上の日本人有権者を対象とし、最終的に1,191人の有効回答が得られた。回答者は、実験刺激文を読んだ後、投票参加意向やオンライン投票利用意向などに関する質問に回答した。実験刺激文は、従属変数の質問の直前の画面で提示され、回答者は一度読んだ内容を読み返すことはできない設計となっている。

## 2. 変数の測定方法

本節では、セクション3で提示されたそれぞれの仮説に登場する変数（X, Y, M, Z）がどのように測定されたかを説明する。

### 2.1 従属変数（Y）

#### 2.1.1 Y1：投票参加意向

投票参加意向は、以下の質問文によって測定された。

「リバティアの選挙では、投票日に投票所に直接行って対面で行う投票と、投票日前に居住地の役所で対面で行う期日前投票【、それから自宅で個人識別番号（日本でいうマイナンバー）を使って行うオンライン投票】が認められています。あなたがリバティアの有権者だとすると、次の選挙で投票する可能性はどれくらいあるでしょうか。１を「まったくない」、１０を「確実にある」として、１から１０の数字で答えてください。」

なお、【】内の「それから自宅で個人識別番号（日本でいうマイナンバー）を使って行うオンライン投票」という記述は、オンライン投票非導入群（`exp2_onlinevote = 0`）では表示されない。

回答選択肢は1（まったくない）から10（確実にある）の11段階スケールである。記述統計によると、投票参加意向の平均値は7.98（標準偏差2.16）、最小値は1、最大値は10であり、有効ケース数は1,186（欠損5）であった。

#### 2.1.2 Y2：オンライン投票利用意向

オンライン投票利用意向は、以下の質問文によって測定された。

「それでは、次の各方法で投票する可能性はどれくらいあるでしょうか。同じく、１を「まったくない」、１０を「確実にある」として、１から１０の数字で答えてください。」

この質問では、以下の3つの投票方法について、それぞれ投票する可能性を尋ねた：
- 投票日に投票所で対面投票（`exp2_q1b_1`）
- 投票日より前の日に居住地の役所で期日前投票（対面）（`exp2_q1b_2`）
- オンライン投票（`exp2_q1b_3`）

本論文では、オンライン投票利用意向として`exp2_q1b_3`を使用する。なお、H2B、H3B、H4、H5Cの検証においては、オンライン投票導入群（`exp2_onlinevote = 1`）にサンプルを限定する。

記述統計によると、オンライン投票利用意向の平均値は7.15（標準偏差2.72）、最小値は1、最大値は10であり、有効ケース数は793（欠損398）であった。欠損値が多いのは、オンライン投票非導入群（`exp2_onlinevote = 0`）ではこの質問が表示されないためである。

### 2.2 独立変数（X）

#### 2.2.1 X1：オンライン投票導入

オンライン投票導入は、実験刺激文においてオンライン投票が利用可能であることを示す情報が提示されたかどうかによって測定された。具体的には、実験刺激文に「リバティアでは、オンライン投票が可能です。」という記述が含まれていた場合を1（導入）、含まれていなかった場合を0（非導入）とするダミー変数として扱った（変数名：`exp2_onlinevote`）。

実験刺激文は、従属変数の質問の直前の画面で提示された。記述統計によると、オンライン投票非導入群（0）は396人（33.2%）、オンライン投票導入群（1）は795人（66.8%）であった。

#### 2.2.2 X2：政府への信頼

政府への信頼は、実験刺激文において政府の選挙運営に関する透明性が高い情報が提示されたかどうかによって測定された。具体的には、以下のような情報が提示された場合を1（高）、そうでない場合を0（低）とするダミー変数として扱った（変数名：`exp2_govtH`）。

**政府信頼高（`exp2_govtH = 1`）の実験刺激文：**
「リバティアの政府は、民主的な選挙制度を長年にわたり維持しており、選挙の透明性を確保するための制度や手続きがすでに整備されています。例えば、０票確認、開票作業の中継、第三者集団による選挙フロー全体の監視などが実施されています。選挙運営に関する政府の説明については、多くの国民から透明性が高いと評価されています。選挙管理委員会は、独立した機関として機能し、選挙の公正な実施に貢献していると一般的に認識されています。」

**政府信頼低（`exp2_govtH = 0`）の実験刺激文：**
「リバティアの政府は、民主的な選挙制度を長年にわたり維持していますが、選挙の透明性を確保するための制度や手続きに改善の余地があります。例えば、０票確認、開票作業の中継、第三者集団による選挙フロー全体の監視などが実施されていない状況です。選挙運営に関する政府の説明については、一部の国民から透明性が低いと評価されています。選挙管理委員会は、独立した機関として機能し、選挙の公正な実施に貢献していると一般的に認識されています。」

記述統計によると、政府信頼低群（0）は594人（49.9%）、政府信頼高群（1）は597人（50.1%）であった。

#### 2.2.3 X3：技術への信頼

技術への信頼は、実験刺激文においてオンライン投票システムの技術的信頼性が高い情報が提示されたかどうかによって測定された。具体的には、以下のような情報が提示された場合を1（高）、そうでない場合、またはオンライン投票が導入されていない場合を0（低/非導入）とするダミー変数として扱った（変数名：`exp2_techH`）。

**技術信頼高（`exp2_techH = 1`）の実験刺激文：**
「リバティアのオンライン投票システムは厳しい国際標準に準拠して設計されており、暗号化技術や二要素認証などの最新のセキュリティ対策を採用しています。すでに10年に渡り運用されていますが、外部からの不正アクセスに対するソフトウェアの脆弱性に関するインシデントは一度も報告されていません。システムの技術的な堅牢性と、投票記録の監査可能性を維持するため、複数の独立した専門機関によるセキュリティ監査が定期的に行われています。」

**技術信頼低（`exp2_techH = 0`）の実験刺激文：**
「リバティアのオンライン投票システムは厳しい国際標準に準拠して設計されており、暗号化技術や二要素認証などの最新のセキュリティ対策を採用しています。10年に渡り運用されてきた中で、外部からの不正アクセスに対するソフトウェアの脆弱性に関するインシデントが数回報告されていますが、情報漏洩は確認されていません。システムの技術的な堅牢性と、投票記録の監査可能性を維持するため、複数の独立した専門機関によるセキュリティ監査が定期的に行われています。」

記述統計によると、技術信頼低/非導入群（0）は793人（66.6%）、技術信頼高群（1）は398人（33.4%）であった。

### 2.3 条件付け変数（M）

#### 2.3.1 M1：政治関心

政治関心は、以下の質問文によって測定された（変数名：`polint`）。

「あなたは政治に関心がありますか、それとも有りませんか」

回答選択肢は以下の4つである：
- 1：関心がある
- 2：ある程度関心がある
- 3：あまり関心がない
- 4：関心がない

度数分布によると、回答者の分布は以下の通りであった：関心がある（1）251人、ある程度関心がある（2）669人、あまり関心がない（3）244人、関心がない（4）27人。

分析においては、この変数を連続変数として扱うため、以下のようにリコードした（変数名：`kanshin`）：
- 1（関心がある）→ 1
- 2（ある程度関心がある）→ 0.5
- 3（あまり関心がない）→ 0
- 4（関心がない）→ 0

リコード後の記述統計によると、政治関心の平均値は0.49（標準偏差0.33）、最小値は0、最大値は1であり、有効ケース数は1,191であった。

#### 2.3.2 M2：SNS利用頻度

SNS利用頻度は、以下の質問文によって測定された（変数名：`useinternet`）。

「あなたは仕事用・個人用を問わず、コンピューター、タブレット、スマートフォンなどでインターネットを平日の１日に平均でどのくらいの時間利用しますか。」

回答選択肢は以下の7つである：
- 1：ほとんど使わない
- 2：30分くらい
- 3：1時間くらい
- 4：2時間くらい
- 5：3時間くらい
- 6：4時間くらい
- 7：5時間以上

分析においては、この変数を連続変数として扱った。記述統計によると、SNS利用頻度の平均値は5.65（標準偏差1.42）、最小値は2、最大値は7であり、有効ケース数は1,191であった。

#### 2.3.3 M3：政府の責任認識

政府の責任認識は、以下の共通質問文の下で、2つの項目について尋ねた質問の回答を組み合わせて測定した。

「日本の景気のよしあしや、あなた自身のくらし向きの変化に関して、政府の責任はどの位あると思いますか。それぞれについてあなたの考えに一番近いものをお答えください。」

- `gvtresp_1`：日本の景気のよしあし
- `gvtresp_2`：あなた自身の暮らし向き

それぞれの回答選択肢は以下の4つである：
- 1：大きな責任がある
- 2：ある程度責任がある
- 3：少しは責任がある
- 4：あまり責任はない

`gvtresp_1`の度数分布は以下の通りであった：大きな責任がある（1）718人、ある程度責任がある（2）376人、少しは責任がある（3）87人、あまり責任はない（4）10人。

`gvtresp_2`の度数分布は以下の通りであった：大きな責任がある（1）203人、ある程度責任がある（2）497人、少しは責任がある（3）401人、あまり責任はない（4）90人。

分析においては、`gvtresp_1`と`gvtresp_2`の平均値を計算し、それを政府の責任認識として使用した（変数名：`gvtresp_mean`）。平均値の計算は、両方の変数が欠損値でない場合のみ行い、どちらか一方でも欠損値がある場合は除外した。平均値の範囲は1から4であり、分析ではそのまま使用した。

記述統計によると、政府の責任認識の平均値は1.90（標準偏差0.63）、最小値は1、最大値は4であり、有効ケース数は1,191（欠損0）であった。

### 2.4 交絡変数（Z）

交絡変数として、以下の変数を分析において統制した。

- Z1：政府への信頼（`exp2_govtH`）- H1、H3の分析において統制
- Z2：技術への信頼（`exp2_techH`）- H1、H2の分析において統制
- Z3：オンライン投票導入（`exp2_onlinevote`）- H2、H3の分析において統制

これらの変数の測定方法は、上記の独立変数（X）の説明と同様である。

## 3. 値の調整と組み合わせの手続き

本節では、回答選択肢の値を調整したり、複数の質問に対する回答を組み合わせた場合の手続きについて説明する。

### 3.1 政治関心のリコード

政治関心（`polint`）については、分析において連続変数として扱うため、4段階のカテゴリ変数を0から1の連続変数にリコードした。具体的には、1（関心がある）を1、2（ある程度関心がある）を0.5、3（あまり関心がない）および4（関心がない）を0として扱った。このリコードにより、政治関心が高いほど値が大きくなる連続変数として分析に投入することが可能となった。

### 3.2 政府の責任認識の平均値計算

政府の責任認識については、`gvtresp_1`（日本の景気のよしあしに対する政府の責任）と`gvtresp_2`（あなた自身の暮らし向きに対する政府の責任）の2つの質問に対する回答の平均値を計算した。平均値の計算は、両方の変数が欠損値でない場合のみ行い、どちらか一方でも欠損値がある場合は除外した。これにより、政府の責任認識を1つの指標として統合することが可能となった。
